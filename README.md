## About This Repository

This repository contains the source code for practical assignments focused on implementing fundamental data structures and algorithms using C++.

Each practical demonstrates a specific concept through problem-solving applications, including arrays, hashing, searching, linked lists, stacks, queues, trees, and deques.

## Practical Assignments

| Practical | Topic | Description |
|---|---|---|
| **01** | Arrays Operation | Implement array-based applications such as Student Mark Analysis, Movie Ticket Booking, or Inventory Management. |
| **02** | Hashing Operation | Implement hashing applications using hash functions and linear probing to resolve collisions. |
| **03** | Search and Sorting | Store friends' names and mobile numbers in sorted order, search using sentinel search, and insert a friend if not found. |
| **04** | Linked List | Implement an application using a singly, doubly, or circular linked list, such as Call Log Management, Train Reservation, or Music Playlist Management. |
| **05** | Stack | Implement a stack using two queues. |
| **06** | Queue | Implement a queue using a linked list and implement a queue using two stacks. |
| **07** | Trees | Design a task scheduler where tasks can be added at the front and rear, with high-priority tasks processed first. |
| **08** | Graph / Deque | Implement a program to check whether a given string is a palindrome using a deque. |

## How to Run

### 1. Clone the repository

```bash
git clone https://github.com/Siddharth9520/DSA-Practical-Assignments.git
```

### 2. Navigate to the repository

```bash
cd DSA-Practical-Assignments
```

### 3. Compile a practical

For example, to compile Practical 01:

```bash
g++ Practical_Assignment01.cpp -o practical
```

### 4. Run the program

On Windows:

```bash
.\practical.exe
```

On Linux or macOS:

```bash
./practical
```

Replace the filename with the relevant source file for the practical you want to execute.
